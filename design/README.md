## 设计方向

- **冷静、支持、不评判**：不做恐吓式控烟广告，不用红色警告刷屏。
- **主色深青绿**：健康、稳定、可依靠。
- **渴求入口用琥珀色**：提醒但不制造恐慌。
- **大量留白 + 圆角卡片**：降低医疗感，接近日常健康 App。
- **首屏只放 4 个数字**：戒烟天数、少抽支数、省钱、延迟分钟/熬过波数。

## 关键交互状态（开发时按这个实现）

### 首页

- 顶部：`戒烟第 X 天` + `今天无烟/今天已记录` 徽章。
- 4 个数字：少抽支数、省钱、延迟分钟、熬过波数；全部标“估算”。
- 里程碑：下一节点（1 天/3 天/1 周/2 周/1 月/3 月/6 月/1 年）+ 进度条。
- 今日洞察：高危时段 + 最有效方法。
- 全局 CTA：`我现在想抽烟` 固定在首屏显眼位置。

### 渴求入口

- 默认推荐 10 分钟；3 分钟作为快速选项。
- 任务/游戏二选一；不设“赢了才能抽”。
- `我现在要抽` 始终可见，点击后进入记录页，不弹劝阻。

### 延迟结束

- 先给称赞，再问“现在还想抽吗”。
- 默认显示与上次对比：`本次 X 分钟 · 上次 Y 分钟 · +Z 分钟`。
- 比上次少时，仍显示两个数字，但文案给上下文（起始渴求、难度），不做负面标题。
- 最多 3 轮；第三轮后给“记录一支 / 联系支持者 / 再撑 10 分钟”。

### 记录一支

- 标题用“记录一支，没关系”，不用“失败/破戒”。
- 详情可跳过，一键记录。
- 保存后给一条“下一支不抽”的 if-then 建议。

### 数据与研究

- 首次使用页分开授权：本地使用（必需）+ 匿名研究贡献（可选，默认关闭）。
- 分型页记录起始渴求强度；延迟结束记录结束强度。
- 任务 ID、任务版本、分配方式（用户选择/随机）由后台记录，不占用户界面。
- “最有效方法”标注“基于你的数据”；群体效果只在内部后台展示，不混在个人页。
- 没有后端时，先做本地事件日志与 JSON 导出；群体统计属于 P1。

## 开发约定

- 设计稿是 **HTML + CSS 静态稿**，不是最终应用代码；开发时按设计令牌和结构实现，不要直接复制成业务代码。
- 优先实现 P0 页面：01 首页、02 渴求入口、03 分型、04 计时、05 任务、06 延迟结束。
- 记录/统计/周报/设置属于 P0/P1 交界，按开发顺序接。
- 移动端优先 390px；至少兼容 360–430px。
- 触控目标 ≥ 44px；正文对比度 ≥ WCAG AA。
- 无外部字体/图标依赖；图标用内联 SVG 或 CSS。
- 当前只有浅色主题；深色模式、动画、品牌 Logo 待定。
